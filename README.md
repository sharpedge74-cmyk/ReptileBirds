# ReptileBirds - Interactive Word & Puzzle Studio

A fast, zero-bloat interactive word discovery and puzzle solver application for **ReptileBirds** (`reptilebird.com`). Built with React 19, TypeScript, Vite, and Tailwind CSS.

---

## Features

- **Word Finder & Rack Unscrambler**: Live anagram and sub-anagram generator with wildcard support (`?` or `*`), length grouping, and instant 0ms filtering.
- **5-Letter Wordle & Clue Solver**: Interactive deduction board with green (exact spot), yellow (present), and gray (absent) feedback, letter entropy ranking, and candidate probability distribution.
- **Interactive Tile Scorer**: Word point calculator comparing Standard Tournament vs Alternate Digital rules side-by-side with dictionary validation.
- **Curated Word Vault**: In-app exploration of tactical word lists including 2-Letter Words, Q Without U, Palindromes, Vowelless Words, Double Letters, Action Verbs, and Sensory Adjectives.
- **Personal Word Bank**: Save and bookmark high-scoring words, export to CSV or clipboard.
- **Clean Architecture**: 100% genuine interactive web application with zero programmatic SEO doorway pages or sitemap spam.
